# Сервіс ремонту смартфонів

Навчальний вебпроєкт для лабораторної роботи № 5 з дисципліни «Основи програмної інженерії».

## Призначення
Інформаційний сайт сервісу ремонту смартфонів. Головна сторінка описує основні послуги, а сторінка `pricing.html` містить орієнтовний перелік робіт та цін.

## Запуск
Завантажте репозиторій і відкрийте файл `index.html` у браузері. Додаткове програмне забезпечення не потрібне.

## Файли
- `index.html` — головна сторінка;
- `styles.css` — стилі оформлення;
- `pricing.html` — сторінка послуг та орієнтовних цін;
- `.gitignore` — правила ігнорування тимчасових файлів.
